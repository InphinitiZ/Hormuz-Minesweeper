# Hormuz Minesweeper

A Minesweeper game with a Hormuz Strait theme, built as a single-page HTML application.

## How to Play

1. Open `index.html` in a browser
2. Left-click to reveal a cell
3. Right-click to flag a mine
4. Clear all non-mine cells to win

## Tech Stack

- Pure HTML/CSS/JavaScript (single file, no dependencies)
